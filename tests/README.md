# Smoke тестове за DimitTech (статичен сайт)

Това директория съдържа автоматизирани smoke тестове за валидация на основните функционалности и състоянието на статичния сайт.

## Как се пускат тестовете

Тестовете са написани с помощта на вградения тест модул на Node.js (`node:test`) и не изискват външни зависимости (`zero dependencies`).

За стартиране на тестовете изпълнете следната команда от корена на хранилището:

```bash
node --test tests/smoke.test.mjs
```

> Бележка: `node --test tests/` (само папка) не работи в Node 22 — дава `MODULE_NOT_FOUND`. Ползвайте пътя до файла или шаблон: `node --test "tests/*.test.mjs"`.

Алтернативно, за всички тестови файлове в папката:

```bash
node --test "tests/*.test.mjs"
```

## Какво се покрива от тестовете

Автоматизираните smoke тестове в `tests/smoke.test.mjs` извършват следните проверки:

1. **Достъпност на публичните URL адреси (Live URLs):**
   - Проверява чрез HTTP GET заявка (`fetch`), че следните живи адреси връщат статус `200 OK`:
     - `https://dimitarbeograd-qa.github.io/`
     - `https://dimitarbeograd-qa.github.io/privacy.html`
     - `https://dimitarbeograd-qa.github.io/i18n.js`
     - `https://dimitarbeograd-qa.github.io/chat-widget.js`

2. **Заглавни атрибути и Content Security Policy (CSP):**
   - Проверява дали `index.html` и `privacy.html` съдържат валиден `lang` атрибут на тега `<html>` (напр. `lang="bg"`).
   - Проверява дали и двата файла съдържат мета тег за `Content-Security-Policy`.
   - Гарантира, че CSP правилата **не** съдържат опасната директива `'unsafe-eval'`.

3. **Валидност на локалните референции (href / src):**
   - Обхожда всички `href` и `src` атрибути, както и CSS `url(...)` референции в `index.html`.
   - Игнорира котва връзки (`#`), протоколи `mailto:`, `tel:`, `data:` и външни URL адреси (`http://`, `https://`).
   - Потвърждава, че всеки посочен локален файл съществува физически в хранилището (напр. `test-digitalni-kompetentnosti.html`, `privacy.html`, `i18n.js`, `chat-widget.js`, `fonts/dm-sans-latin.woff2`, `fonts/syne-latin.woff2`, `downloads/QA-Pack-BG.zip`).

4. **Двуезичен речник (i18n):**
   - Зарежда файла `i18n.js` като текстов файл.
   - Извлича английския речник (`EN`) и потвърждава, че съдържа поне 200 ключа за превод.

## Какво НЕ се покрива от тестовете

Следните аспекти не са обект на настоящите smoke тестове и изискват E2E, визуално или функционално тестване:

- **Динамично функционално поведение в браузъра:**
  - Изпълнение на JavaScript логиката за хамбургер менюто, скрол анимациите и превключването на езици в реално време.
- **Интеграция на чат уиджета (Chat Widget) и Worker бекенда:**
  - Взаимодействието с AI асистента, изпращането на съобщения и комуникацията с Cloudflare Workers KV / Telegram API.
- **Изпращане на контактната форма:**
  - Отваряне на `mailto:` клиента или реално изпращане на формуляри към външни endpoints.
- **Визуален рендеринг и CSS стилизация:**
  - Проверка на оформлението (layout), крос-браузър съвместимостта изивън статичния код, отзивчивия дизайн (responsive design) за мобилни устройства.
- **Производителност и SEO:**
  - Метрики по Core Web Vitals, скорост на зареждане и съвместимост с търсачки (Lighthouse одит).
