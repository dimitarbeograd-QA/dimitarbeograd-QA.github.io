# DimitTech — IT Solutions & Innovation

Бизнес сайт на DimitTech: персонализирани IT решения, уеб разработка, cloud,
AI, киберсигурност, QA тестване и remote assistance. Едностраничен статичен
сайт (`index.html`), хостван вероятно през GitHub Pages.

## Функционалности
- Hero секция с преглед на услугите
- 9 service карти (Уеб, Мобилни, Cloud, AI, Сигурност, Консултации, QA, Remote, Концепция)
- Процес, технологичен стек, security секция
- Контактна форма с валидация и honeypot anti-spam защита
- Responsive nav с mobile drawer меню

## Стартиране
Статичен `index.html` — не изисква build стъпка.
```
npx serve .
```
