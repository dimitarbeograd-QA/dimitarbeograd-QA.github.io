# Contributing

## Как да допринесеш
1. Направи промените директно в `index.html`.
2. Тествай ръчно по чеклиста в [`qa-docs/TEST_CASES.md`](qa-docs/TEST_CASES.md) — особено формата и navigation.
3. При промяна на CSP или security headers, тествай внимателно — грешна CSP директива може да счупи легитимни ресурси.
4. Тествай responsive поведението на 900px/640px/520px breakpoints.
